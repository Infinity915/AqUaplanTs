1. METHOD COUNCIL (strengths / gaps)
----------------------------------------------------------------
Strongest (keep):
  + Staged binary->multiclass correct for 79% background.
  + Tiling (not 4K resize) preserves GSD for seedlings.
  + Mosaic + copy-paste only viable fix for <0.01% rares.
  + SAHI inference matches train tiling.
  + Tversky recall bias right for Zinda1 90% fg (FN >> FP cost).

Gaps + FIX (adopted in v2):
  [M1] Tile 640/ov128 too small, truncates clumps.
       FIX: train 640 (Kaggle limit) BUT infer SAHI 800 ov240-320 +
            multiscale 0.75/1.0/1.25. List 1024/ov256 as future (needs A10G).
  [M2] NMS kills dense TPs at 90% fg (YOLO-seg is box+NMS dependent).
       FIX: class-agnostic NMS IoU 0.85 + mask-NMS now; name RT-DETR /
            semantic (SegFormer/Mask2Former) as NMS-free follow-up. Do not
            claim congestion solved by tiling alone.
  [M3] P3 stride-8 + min-area 64px deletes seedlings.
       FIX: enable P2 stride-4, min-area 16px, oversample fg tiles 3:1,
            lower Mosaic prob for tiny branch.
  [M4] Tversky-only + median-freq double-counts, collapses background.
       FIX: weighted CE (effective-number, clip 10x) + Dice/Tversky
            a0.7/b0.3 + Focal gamma2.0. Tune on rare-class IoU, not mIoU.
  [M5] Random/tile split leaks sites (90% vs 7% domains).
       FIX: GroupKFold by source image/site; split IMAGES before tiling;
            stratify by density; report per-site. (See Risk fixes.)

Single highest-leverage change per council: go NMS-free (semantic or
RT-DETR) for congestion. Within 3-day Kaggle limit: apply M2-interim
(agnostic NMS 0.85) + document full NMS-free as future work.

3. KAGGLE COUNCIL (hour budget — CRITICAL FINDING)
----------------------------------------------------------------
Verdict: NO-GO as written; YES with filtering. Math:
  yolo11m-seg AMP ~12-18 img/s train. 11.8k tiles x100ep = 1.18M imgs =
  18-27h train alone = ~3x over 9h session / 30h week.
  Fits ONLY if NB0 filters empties to ~3-4k fg tiles:
    NB1 binary 4k x100ep: 0-0.5h setup, 0.5-7.5h train (~400k/15fps=7.4h),
      7.5-8.5h val+export. 8.5-9h marginal PASS.
    NB2 32-cls 4k x70ep: 0.3-6.8h train (280k/12fps=6.5h), 6.8-8h val.
      ~8h PASS, zero slack.

Top failure modes + mitigations (v2 mandatory):
  [K1] OOM seg masks (retina_masks + mosaic >16GB):
       batch 4-6 (not 8), amp=1, workers=2, cache=disk,
       close_mosaic=10, overlap_mask=False, persistent_workers=False.
  [K2] Polygon conversion stall hr0-2:
       pre-filter empties, Douglas-Peucker eps=1.0, cache=False,
       save tiles as Kaggle Dataset for reuse across NBs.
  [K3] Disk 20GB blowup (tiles 6-8GB + runs + cache ~10GB):
       delete raw zip after tiling, save_period=10, plots=False,
       clear ~/.cache/ultralytics, stream push.
  [K4] 9h kill no resume:
       resume=True always, checkpoint push every 10ep to Output/HF,
       split NB2 into 2x35ep sessions if needed.

Ranked cut list if slipping (apply top-down):
  1. SAHI/TTA-full -> flip-only on val subset.
  2. Epochs NB1 100->50, NB2 70->30-40 + patience=15.
  3. Downgrade m->s for NB2 (-2-3 mAP, 2x speedup).
  4. Tiles stride 128->512 or 640->512px (11.8k->3k).
  5. Classes 32 -> binary + top10 agronomic (defer taxonomy).
